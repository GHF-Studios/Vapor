# Glossary

| Term | Meaning |
| --- | --- |
| **App root** | The installed Vapor application instance and its owned runtime, local state, and provider tools. |
| **Composition** | A user's launchable selection: root Packagepack, launch settings, resolved content graph, and installation state. |
| **Content ID** | Stable identity of an authored content item across releases. |
| **Content release** | A versioned, staged runtime artifact with role metadata and declared files. |
| **Crate** | The Vapor content kind for Rust library source; distinct from the product's local Library. |
| **Library** | The player's local collection of available or cached content. It is not synonymous with an installed composition. |
| **Packagepack** | A content root that supplies the required engine and game choices for a playable composition. |
| **Provider** | A controlled external source or destination, such as Steam Workshop, that supplies or publishes artifacts. |
| **Resolved graph** | The exact content releases and dependency edges selected for a composition. |
| **Source workspace** | Editable repository content whose registered projects include Vapor content and/or Cargo packages. |
| **Vapor Client service** | The local stateful process that owns shared application operations for GUI, Shell, and other front ends. |
| **Workshop item** | A Steam-published object identified by a PublishedFileId; it may contain one versioned Vapor content artifact. |
