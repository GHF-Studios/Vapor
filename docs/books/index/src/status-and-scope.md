# Status And Scope

These books are built from checked-in Vapor documentation and are intended to
explain current user and developer workflows. Pages distinguish:

- **Current behavior**, backed by shipped code or a verified operation.
- **Approved direction**, a product decision whose implementation may be open.
- **Unverified behavior**, which needs runtime or platform evidence before it
  can be claimed as working.

The separate Launcher, Studio, and IDE are approved product boundaries, but
the current GUI still combines player and creator workflows. Vapor Client is
the shared operation boundary. Steam provider availability, Windows runtime
packaging, and live Steam execution need explicit platform verification.

A book is not complete merely because it builds. Each page should explain its
audience, operation or concept, ownership boundaries, and failure or current
limits. The publisher rejects placeholder pages before replacing the live site.
