# Vapor Books

Vapor documentation is organized by the work a reader wants to do. Begin with
the book chooser, then use the product, SDK, distribution, or internals guide
that matches the task.

The public docs index reads titles and descriptions from each book's
book.toml, then builds the checked-in mdBook source. Adding a book therefore
does not require another hard-coded title list. The existence of a book does
not mean every described feature is shipped: pages distinguish current
behavior from approved direction and unverified behavior.
