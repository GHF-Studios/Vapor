# Which Book Should I Read?

Choose by task:

- **I want Vapor concepts and vocabulary.** Start with the Vapor Book.
- **I want to author content or use managed developer tools.** Read the SDK
  Book, then use the Cookbook for a concrete recipe.
- **I want to find, install, compose, update, or launch content.** Read the
  Launcher Book.
- **I need to publish an app or Workshop item, or understand release trust.**
  Read the Distribution Book.
- **I am changing Vapor itself.** Start with Internals and inspect repository
  instructions before editing.
- **I need one concrete operation.** Search the Cookbook or the Shell command
  guide.

The approved product direction separates player Launcher, creator Studio, and
code-authoring IDE over the same Vapor Client service. Today some of those
surfaces are still bundled together. The books call out that gap instead of
presenting the planned split as shipped behavior.
