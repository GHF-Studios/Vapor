# Vapor Documentation Books

Vapor's public documentation is split by reader task. Each book has its own
book.toml and SUMMARY.md; the public index derives the book title and
description from its declaration and builds it from its source pages.

- **Vapor Book** — concepts, vocabulary, product boundaries, and lifecycle.
- **SDK Book** — source workspaces, content authoring, managed toolchain, and
  developer commands.
- **Launcher Book** — the intended player journey: discover, install, compose,
  update, repair, and play.
- **Distribution Book** — Steam app delivery, Workshop, identity, trust, and
  release checks.
- **Internals Book** — contributor orientation and implementation ownership.
- **Cookbook** — task-oriented workflows assembled from current commands.
- **Index Book** — route readers to the right starting point.

The approved product direction separates players into Launcher, creators into
Studio, and code authors into IDE. They share Vapor's local service and
canonical content model. Some workflows remain bundled in the current UI; the
books label that implementation gap instead of presenting the target as done.
