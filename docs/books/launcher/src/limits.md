# Limits

The Launcher coordinates content sources and local state; it cannot make an
unavailable provider deliver a payload, grant Steam permissions, or guarantee
that an author's content is free of bugs. A resolved graph proves that Vapor's
declared role and version constraints were satisfied. It is not a sandbox and
does not prove that arbitrary native code is safe.

Workshop search and download require Steam to be available. A subscribed item
can fail to download. A locally installed item can be manually modified after
installation and fail verification. A successful build on one operating
system does not prove another declared platform works.

Vapor uses fingerprints and recorded installation state to detect payload
changes, but fingerprint agreement is not a security review of the program.
Only install content from sources you trust and review platform permissions
and account prompts before a real publication or root-app update.
